# Channel `/tan` 独立分叉任务

日期：2026-11-04

## 用户契约

owner 在已授权主群或子区发送 `/tan <用户请求>`，channel 截获命令，将当前聊天的精确已落盘 OMP session 通过原生 CLI `--fork` 分叉，创建同父群的新子区，并将用户请求作为该子区的独立任务执行。源 worker 不接收 `/tan` 或派发请求，不调用源 worker 的 RPC fork，不切换源 binding，不等待源回合结束。准备 worker 确认退出、ledger 收尾和目标 binding ready 后才能启动目标任务。

子区显示任务、进度、提问和完整结果；源聊天收到目标子区和派发回执。子区的 listen 初始值为既有默认 `merge`；可使用既有命令改为 `task`，按既有策略回传任务终态。目标任务开始后在目标子区 `/cancel`；源聊天的现有 `/cancel` 在准备阶段同时取消源聊天当前任务和该 fork 准备。源聊天的 pending ask 不消费 `/tan` 或目标任务。子区的 `/thread merge` 和 `/thread remove` 仅归档，保留会话和共享目录。

该命令是 channel 创建可见子区和独立 session 的能力，不声称与 OMP 原生 `/tan` 等价。源与目标共享 cwd 和文件：独立会话不隔离文件系统，双方修改相互可见；不创建 worktree，不复制工作区归属，显式破坏操作继续遵守现有资源保护。

## 入站与持久生命周期

命令参数和附件、引用按照现有入站物化规则合成目标任务正文；不发送原始 `/tan`，不以群历史或提示前缀阻碍 channel 命令识别。仅 owner 在现有 allowlist/mention 门禁后使用，历史和派发正文不授予额外权限。空请求给出用法，不创建任务。

目标任务持久保存物化正文原文。若正文以斜杠命令形式开头，发送给 OMP 时仅在前面加 `用户请求：` 标记，避免 OMP 把用户请求解释为原生命令；后续恢复使用相同规则。

持久接受必须在释放入站处理前原子记录完整物化正文、源聊天与消息身份、源 session ID、精确文件和 cwd，以及唯一 fork 操作身份；之后的准备和投递由受服务生命周期跟踪的操作推进。物化之前的临时 claim 若在进程退出时尚未转为持久接受，重启后须允许原消息重投；已接受操作保持去重。原始消息重投不能产生第二个 fork 或第二次目标任务。目标任务使用稳定输入身份、既有持久任务接受和独立聊天调度，不走 pending ask 或 steer 路径。准备和恢复只使用接受时捕获的精确源身份；不猜最近会话、不重放源 prompt。

复用 `thread_forks` 和创建意图记录各阶段；准备进程、watchdog、共享资源使用与关闭遵循现有 fork 契约。启动时扫描已接受但未终结的请求，并核对其 fork 和目标任务：确定安全的阶段继续交接；失败、未知分配或未知进程状态持久报告，不盲目重建。准备失败报告已确认部分；未知远端分配不能自动再创建。目标任务已持久接受后，服务重启沿既有任务 dispatch intent、实际 agent_start 和精确 session 恢复规则处理；未知接受不重新发送请求。目标 ready 到任务受理之间的中断须能以稳定身份安全完成交接，不重新 fork。

源 `/cancel` 在回复前持久记录对尚未交接的请求的取消，目标受理与取消串行决定，恢复时已取消请求不能派发，即使远端子区身份已知。目标 fork 的 session ID、文件和 cwd 是任务的持久约束：接受和首次派发均核对目标绑定；绑定改变时失败并报告，不改用新会话执行。关停取消在途准备并等待所有跟踪操作收尾；不因进程退出不明而开放目标或释放资源。

## 验收

- 使用 held 源任务和精确源 session，验证目标独立启动、继承落盘上下文且只收到物化后的用户请求，源 session、binding 和任务不变。
- 验证重复投递、准备失败、未知远端分配、目标受理边界、未知 prompt 接受、取消和重启，不重复创建或执行；worker、watchdog 与资源 lease 有明确收尾。
- 验证 owner/群权限、pending ask、附件/引用、结果位置、listen 和 fork 子区仅归档行为。
- 使用真实安装 OMP、隔离 profile/session、有限 localhost 模型、本地 Octo 加密协议 fixture 和临时目录验证端到端；运行 fork/core/worker 回归、typecheck、完整测试及离线 fork/restart benchmark，不连接真实 provider 或常驻 bot。
